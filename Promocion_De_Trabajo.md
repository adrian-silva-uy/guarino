## 1. RESUMEN EJECUTIVO

GuarinoApp es una aplicación web Blazor Server (.NET 8) para la gestión completa de operaciones citrícolas, incluyendo pesadas, stock de pallets, empaque, liquidaciones, contaduría, gerencia, riesgos climáticos y asistente IA.

El sistema está completamente desarrollado, probado y en funcionamiento. A continuación se presenta el estimado de precio para la adquisición, licenciamiento y mantenimiento del sistema.
